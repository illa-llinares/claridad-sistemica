# Claridad Sistémica · Illa Llinares

Web de Claridad Sistémica con Illa Llinares, disponible en español e inglés.

Web publicada: https://systemic-clarity-illa-llinares.cerebro-en-l-4950.chatgpt.site/

## Archivos

- `dist/index.html`: contenido y estructura.
- `dist/style.css`: diseño y adaptación a móvil.
- `dist/app.js`: idiomas, navegación y carrusel de testimonios.
- `dist/*.png`: logo y retrato.
- `.openai/hosting.json`: configuración de publicación con Sites.

La web es estática, sin dependencias de compilación. Para verla localmente, sirve la carpeta `dist` con un servidor HTTP.

## Actualización

GitHub conserva una copia versionada del proyecto. La publicación de la web se gestiona con Sites; un commit en GitHub por sí solo no publica cambios.

Codex debe sincronizar los cambios autorizados mediante el plugin de GitHub, usando una rama y una pull request, y fusionar cuando las comprobaciones hayan terminado correctamente. Una revisión periódica en Codex comprueba si quedan cambios pendientes. Las instrucciones completas están en `AGENTS.md`.
